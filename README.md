# Boomerang
A split, wireless, low profile keyboard. Inspired by the [Corne](https://github.com/foostan/crkbd) and [Caldera](https://github.com/christianselig/caldera-keyboard).

## Tutorial
### Material list
Besides the soldering equipment, you will need:

- Case x2 - [files](/case/)
- Switch plate x2 - [files](/case/)
- PCB x2 - [gerbers](/gerbers/) / [pcb](/pcbs/)
- Pro Micro nRF52840 [or similar](https://github.com/joric/nrfmicro/wiki/Alternatives) x2
- Choc V1 switches x38
- Choc V1 keycaps x38
- Lithium-ion batteries x2
- Spacers M3 8mm x14
- Screws M3 6mm x28
- On / Off switch (SS-12D00) x2
- Reset button x2
- Rubber bumpers x8
